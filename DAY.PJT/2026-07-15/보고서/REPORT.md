## 학습 결과

- 가장 크게 이해한 개념: 꼼꼼한 개인 습관이 팀 규약이 되려면 문서, Template, 역할, Review, 강제 설정이 필요하다.
- 가장 좋은 판단: 기획자에게 Git 전체를 요구하지 않고 업무 관리자와 파일 수정자의 흐름을 분리한 것.
- 가장 가치 있는 기술적 발견: Unity에서 `.meta`는 부가 파일이 아니라 참조를 유지하는 핵심 데이터라는 점.
- 가장 실용적인 운영 판단: 중간 Commit을 과도하게 통제하기보다 PR 품질과 Squash merge로 `release` 기록을 관리하는 것.
- 스스로 발견한 개선점: Commit 제목은 GitHub 문서만 설명했지만 코딩 컨벤션과 DOTween 관련 설정까지 함께 포함됐다.
