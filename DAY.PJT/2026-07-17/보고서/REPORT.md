## 오늘 구현한 흐름

```text
TileGrid
-> 아직 검증되지 않은 가변 원시 데이터

TileLayout
-> MapFactory만 생성 가능
-> 복사 금지, 이동 허용
-> 외부 수정 인터페이스 없음
-> 최소 읽기 질의만 제공
```

## 핵심 성과

- `Map.h`의 원시 데이터 별칭을 독립시켜 불필요한 의존성을 줄였다.
- 클래스 존재만으로 유효성이 보장되는 것이 아니라 생성 제한과 수정 차단이 함께 필요하다는 점을 코드에 반영했다.
- 검증 여부를 별도 `bool` 플래그로 저장하지 않고 `TileLayout` 타입 자체로 표현했다.
- 통행 가능 여부는 `TileLayout`이 아니라 `Map`의 게임 규칙으로 남겼다.
- 전체 Grid Getter와 Setter를 제공하지 않아 불변 조건이 외부에서 깨지는 경로를 줄였다.
- 한국어 주석의 인코딩 경고를 프로젝트 기준인 UTF-8 BOM으로 해결했다.
