# 반복 프로젝트

- 이름: C++ 자료구조 평일 1시간 학습
- 주요 목적: 자료구조를 처음 접하는 학습자가 C++로 핵심 구조를 이해·구현하고, 다른 사람에게 정확하고 쉽게 설명할 수 있게 된다.
- 세부 정보: 총 25회 과정이다. 진도보다 이해를 우선하고, 매회 마지막에는 반드시 말로 설명하는 연습을 한다.
- 진행 기간: 2026-07-21 ~ 25회 완료 시
- 종료 조건: 25회 학습과 최종 10분 모의 수업을 완료하고, 최종 평가표에서 모든 필수 항목이 3점 이상이다.
- 상태: 진행 중

## 생성될 TODO 정보 및 생성 간격

- TODO 이름: C++ 자료구조 N일차 학습
- 유형: 반복
- 생성 간격: 주 5회, 실제 공부하는 날마다 1개
- 실행 시간: 60분
- 완료 기준: 개념 학습, 손 추적, C++ 예제 이해 또는 작성, 자가 문제, 3분 설명을 모두 수행한다.

## 매회 60분 고정 루틴

| 시간 | 활동 | 목적 | 남길 증거 |
|---|---|---|---|
| 0~5분 | 전날 내용을 보지 않고 말하기 | 장기 기억 확인 | 기억난 핵심 3개 |
| 5~20분 | 오늘의 개념을 비유와 그림으로 이해 | 직관 만들기 | 한 문장 정의 |
| 20~35분 | 종이에 연산 과정을 손으로 추적 | 내부 동작 이해 | 상태 변화 표 또는 그림 |
| 35~50분 | C++ 예제를 읽거나 직접 작성 | 개념과 코드 연결 | 핵심 코드와 줄별 설명 |
| 50~57분 | 확인 문제 3~5개 풀기 | 오개념 발견 | 답과 이유 |
| 57~60분 | 중학생에게 설명하듯 3분 말하기 | 가르치는 능력 훈련 | 막힌 표현 1개 |

## 시간이 부족한 날의 최소 루틴 20분

학습을 아예 건너뛰는 대신 아래만 수행한다. 단, 25회 중 최소 루틴은 5회를 넘기지 않는다.

1. 5분: 핵심 정의 읽고 자신의 말로 다시 쓴다.
2. 7분: 예시 데이터 하나를 손으로 추적한다.
3. 5분: C++ 핵심 코드 한 조각을 읽는다.
4. 3분: 소리 내어 설명한다.

## 작성할 보고서 양식 및 작성 간격

- 작성 간격: 매 학습일 종료 직후
- 기록 항목: 실제 학습 시간, 오늘의 한 문장, 코드 이해도, 틀린 문제, 3분 설명에서 막힌 부분, 다음 시작점

## 이해 여부 판정 규칙

다음 네 질문에 자료를 보지 않고 답할 수 있어야 그날 내용을 이해한 것으로 본다.

1. 이것은 무엇인가?
2. 왜 필요한가?
3. 데이터가 들어오거나 나갈 때 내부에서 무슨 일이 일어나는가?
4. 언제 쓰고 언제 쓰지 말아야 하는가?

하나라도 답하지 못하면 실패가 아니라 `보충 필요`로 기록하고, 다음 날 첫 5분에 다시 설명한다.

## 운영 규칙

- 반복 유형 TODO는 TODO.PJT에서 직접 만들지 않는다.
- 반복 TODO는 이 반복 프로젝트를 기준으로 DAY.PJT 날짜 폴더에 스냅샷으로 배치한다.
- 코드를 외우지 않는다. 데이터가 어떻게 움직이는지를 먼저 설명한 뒤 코드를 연결한다.
- 정답만 맞힌 경우보다 틀린 이유를 설명한 경우를 더 높은 이해로 본다.
- `std::vector`, `std::stack` 같은 표준 도구 사용법과 직접 구현을 구분한다.
- 직접 구현은 내부 원리를 배우기 위한 연습이며, 실제 프로그램에서는 검증된 표준 라이브러리를 우선한다.
