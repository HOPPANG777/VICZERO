# 장기 프로젝트

- 이름: C++ 자료구조 5주 — 기초부터 다른 사람에게 설명하기까지
- 목적 및 방향성: 자료구조를 암기 과목이 아니라 “데이터를 어떤 규칙으로 보관하고 다룰지 선택하는 방법”으로 이해한다. 쉬운 말, 손 그림, C++ 코드, 선택 근거의 네 단계로 설명할 수 있게 한다.
- 달성 목표: 핵심 자료구조의 개념·연산·시간 복잡도·장단점을 설명하고, C++로 기본 동작을 구현하거나 STL을 올바르게 선택하며, 10분짜리 입문 수업을 진행한다.
- 진행 기간: 2026-07-21 ~ 25회 완료 시
- 목표 기간: 주 5회 × 5주, 총 25시간
- 상태: 진행 중
- 중단 조건: 없음. 일정이 밀리면 종료 날짜만 연장하고 학습 순서는 유지한다.
- 다음 점검일: 5회차 종료 직후

## 최종 완료 기준

- [ ] 자료구조, 추상 자료형, 알고리즘의 차이를 자신의 말로 설명한다.
- [ ] 배열, 연결 리스트, 스택, 큐, 해시 테이블, 트리, 힙, 그래프를 일상 비유와 정확한 용어로 각각 설명한다.
- [ ] 각 구조의 삽입·삭제·탐색·접근 과정을 작은 데이터로 손 추적한다.
- [ ] 핵심 연산의 대표 시간 복잡도를 말하고 그 이유를 설명한다.
- [ ] C++ STL 컨테이너를 요구사항에 맞게 선택한다.
- [ ] 배열 기반 스택, 연결 리스트 또는 큐 중 하나를 도움 없이 구현한다.
- [ ] 낯선 문제에서 필요한 연산을 먼저 찾고 적합한 자료구조를 고른다.
- [ ] 10분 모의 수업 후 질문 5개 중 4개 이상에 정확히 답한다.

## 평가 척도

각 항목을 0~4점으로 평가한다.

| 점수 | 판정 기준 |
|---|---|
| 0 | 용어를 처음 보거나 답하지 못한다. |
| 1 | 이름과 외운 정의만 말할 수 있다. |
| 2 | 예시는 들 수 있지만 내부 동작이나 예외를 설명하기 어렵다. |
| 3 | 정의, 내부 동작, 복잡도, 사용 시점을 정확히 설명한다. |
| 4 | 쉬운 비유 뒤 정확한 용어로 다시 설명하고, 질문과 반례에도 답한다. |

최종 통과 조건은 모든 필수 주제 3점 이상, 배열·스택·큐·해시·트리 중 세 주제 이상 4점이다.
